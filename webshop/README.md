# Minecraft Webshop 🎮

เว็บไซต์ร้านค้าไอเทม Minecraft ขนาดเล็ก พร้อมระบบพ้อยและการเชื่อมต่อ RCON

## ✨ ฟีเจอร์หลัก

- 🔐 **ระบบเข้าสู่ระบบ** - ใส่ชื่อผู้เล่น Minecraft
- 💰 **ระบบพ้อย** - เติมและใช้พ้อยในการซื้อไอเทม
- 🛒 **ร้านค้าไอเทม** - ซื้อไอเทมต่างๆ ในเกม
- ⚙️ **ระบบ RCON** - ส่งไอเทมเข้าเกมอัตโนมัติ
- 🎨 **UI สวยงาม** - ออกแบบด้วย CSS3 และ JavaScript

## 📁 โครงสร้างไฟล์

```
webshop/
├── index.html          # หน้าหลักของเว็บไซต์
├── style.css          # สไตล์และการออกแบบ
├── script.js          # JavaScript สำหรับฟังก์ชันต่างๆ
├── rcon.php           # ระบบ RCON สำหรับส่งคำสั่งไปเซิร์ฟเวอร์
├── config.php         # การตั้งค่าระบบ
├── database.sql       # โครงสร้างฐานข้อมูล (ถ้าต้องการใช้)
└── README.md          # คู่มือการใช้งาน
```

## 🚀 การติดตั้ง

### 1. อัปโหลดไฟล์

อัปโหลดไฟล์ทั้งหมดไปยัง Web Server ที่รองรับ PHP

### 2. ตั้งค่า RCON

แก้ไขไฟล์ `rcon.php` และ `config.php`:

```php
// ใน rcon.php
$RCON_HOST = 'your-server-ip';     // IP ของเซิร์ฟเวอร์ Minecraft
$RCON_PORT = 25575;                // พอร์ต RCON
$RCON_PASSWORD = 'your-password';  // รหัสผ่าน RCON
```

### 3. ตั้งค่าเซิร์ฟเวอร์ Minecraft

เพิ่มการตั้งค่าใน `server.properties`:

```properties
enable-rcon=true
rcon.port=25575
rcon.password=your-password
```

### 4. ฐานข้อมูล (ถ้าต้องการ)

หากต้องการใช้ฐานข้อมูลแทน localStorage:

1. สร้างฐานข้อมูล MySQL
2. นำเข้าไฟล์ `database.sql`
3. แก้ไขการตั้งค่าใน `config.php`

## 🎯 การใช้งาน

### สำหรับผู้เล่น

1. **เข้าสู่ระบบ** - ใส่ชื่อผู้เล่น Minecraft
2. **เติมพ้อย** - คลิกปุ่ม "เติมพ้อย" เพื่อรับพ้อยฟรี
3. **ซื้อไอเทม** - เลือกไอเทมที่ต้องการและคลิก "ซื้อ"
4. **รับไอเทม** - ไอเทมจะถูกส่งเข้าเกมอัตโนมัติ

### สำหรับแอดมิน

1. **เพิ่มสินค้า** - ใช้ฟอร์ม "เพิ่มสินค้าใหม่"
2. **กำหนดคำสั่ง** - ใส่คำสั่ง RCON ที่ต้องการ
3. **ตั้งราคา** - กำหนดราคาเป็นพ้อย

## 🛠️ คำสั่ง RCON ตัวอย่าง

```bash
# ให้ไอเทม
give {player} diamond_sword 1

# ให้หลายไอเทม
give {player} iron_helmet 1; give {player} iron_chestplate 1

# ให้เงิน (ถ้าใช้ปลั๊กอิน Economy)
eco give {player} 1000

# เทเลพอร์ต
tp {player} 100 64 100

# ให้ Experience
xp add {player} 100
```

## 🔧 การปรับแต่ง

### เพิ่มสินค้าใหม่

แก้ไขใน `script.js`:

```javascript
let shopItems = [
    { 
        id: 1, 
        name: 'ชื่อสินค้า', 
        price: 100, 
        command: 'give {player} item_name 1' 
    }
];
```

### เปลี่ยนสีธีม

แก้ไขใน `style.css`:

```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    --accent-color: #ffd700;
}
```

## 🐛 การแก้ไขปัญหา

### RCON ไม่ทำงาน
1. ตรวจสอบการตั้งค่า `server.properties`
2. ตรวจสอบ Firewall
3. ตรวจสอบรหัสผ่าน RCON

### ไอเทมไม่เข้าเกม
1. ตรวจสอบคำสั่ง RCON
2. ตรวจสอบชื่อผู้เล่น
3. ดู Log ใน `purchases.log`

### หน้าเว็บไม่แสดง
1. ตรวจสอบ PHP Version (ต้อง 7.0+)
2. ตรวจสอบ File Permissions
3. ตรวจสอบ Error Log
